# AGENTS.md — alt-linux-update-script

Общение с пользователем и все новые тексты (вывод скриптов, комментарии, документация) — **на русском языке**.

Два автономных Bash-скрипта для **Alt Linux** (пакетный менеджер `epm`, apt-rpm). Нет сборки, тестов и CI.

| Скрипт | Нужны права root? | Назначение |
|--------|-------------------|------------|
| `up` | **да** (проверяет `EUID`) | Обновление системы (`epm -y ei` + `epm -y full-upgrade`), опциональная установка приложений |
| `yt` | нет | Обёртка для скачивания YouTube через `yt-dlp` |

Оба скрипта — `#!/bin/bash`, используют bash-only возможности (`[[ ]]`, `declare -A` в `up`) — не запускать через `sh`. В каждом скрипте есть `VERSION="x.y.z"` вверху, она логируется при запуске.

## Ключевые неочевидные детали

### `up` — обновление системы и установка приложений
- Работает с `set -e` — любая ошибка прерывает выполнение. `trap` обрабатывает INT/TERM.
- `--install` (`-i`) ставит через `epm -y install`: `git`, `code` (vscode), `ffmpeg`, `python3-module-pip` (pip).
- yt-dlp **не** ставится через epm — скачивается с GitHub releases (`latest/download/yt-dlp`) в `/opt/yt-dlp/yt-dlp`, симлинки на `/usr/local/bin/yt-dlp` и `/usr/bin/yt-dlp`. Требуется `curl`.
- Чтобы добавить приложение в `--install`, правь список пакетов в `main()` (~строка 190). Мапы `declare -A` (`app_command_map`/`app_display_name_map`) только переопределяют имя команды/отображаемое имя; для отсутствующих записей берётся имя пакета.
- Всегда выполняет `update_indexes`, затем `perform_full_upgrade`, даже при `--install`.

### `yt` — загрузчик YouTube
- **Требует** `*cookies.txt` где-то под `$HOME` (рекурсивно выбирает самый свежий); иначе выход.
- Спуфинг Android-клиента против 403: `--extractor-args "youtube:player_client=android,web_embedded,tv"` (android — основной анти-403, web_embedded/tv — фолбэк). Мобильный `--user-agent` намеренно **не** задаётся: он ведёт на `m.youtube.com`, который на целевой системе не резолвится (ломает скачивание каналов).
- `-u`/`--url` обязателен и забирает следующий аргумент как URL; флаги принимаются в любом порядке, но висящий в конце `-u` без значения оставляет `URL` пустым → ошибка.
- `-y N`/`--years N` и `-m N`/`--months N` ограничивают скачивание по дате (`--dateafter now-Nyear` / `now-Nmonth`); фильтр действует на все элементы (каналы, shorts, плейлисты), т.к. записи извлекаются полностью.
- Дату-фильтр yt-dlp применяет только **после полной экстракции** записи (tab-записи каналов не содержат даты). Поэтому при `-y`/`-m` добавляется `--break-on-reject`: табы отсортированы новые→старые, и загрузка останавливается на первой записи старше cutoff вместо перемалывания всего канала.
- Sleep-задержки включаются **автоматически для bulk-загрузок** (канал/плейлист/tab) по детекции URL в `is_bulk_download()`: `--sleep-requests 2 --sleep-interval 10 --max-sleep-interval 20`. `--sleep-interval` срабатывает только перед скачиванием медиа (после успешной экстракции); реальный поток запросов экстракции (~6 запросов на видео) растягивает именно `--sleep-requests` — это основная защита от rate-limit YouTube. Одиночные видео качаются без задержек. Детекция: single = `youtu.be/<id>`, `/watch?v=`, `/shorts/<id>`, `/embed/`, `/live/<id>` без `list=`; всё остальное — bulk.
- Видео: `-f b --recode-video mp4` → `~/video/<uploader>/<title>.mp4`; аудио (`-a`): `bestaudio/best --extract-audio --audio-format mp3` → `~/audio/<uploader>/<title>.mp3`.
- Предупреждения yt-dlp скрыты по умолчанию; `-d` показывает их. Команда собирается через `eval` (легаси-паттерн).

## Тестов нет
Только ручная проверка. Запускать скрипты на Alt Linux для валидации.

## Версионирование
Все скрипты объявляют `VERSION="x.y.z"` вверху. Инкрементировать при изменении логики (конвенция из RULES.md).
